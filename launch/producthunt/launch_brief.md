## 2. Product Description

VibeHacking is an all-in-one open-source offensive & defensive cybersecurity mastery platform engineered to remove the friction from cybersecurity education.

### Key Pillars:
1. **75 In-Depth Textbook Sections**:
   Comprehensive coverage spanning binary exploitation, reverse engineering, kernel exploitation, EDR telemetry bypass, cloud/Kubernetes security, quantum-resistant cryptography (PQC), confidential computing (TEE), and autonomous AI agent red teaming (492 complete chapters across KO, EN, JA, ZH).
2. **70 Reproducible Docker Labs**:
   Self-contained, production-grade vulnerable lab environments with automated regression tests, exploit solvers, and defensive remediations—including **Lab 67: Confidential AI Inference & Hardware TEE Remote Attestation Lab** (`127.0.0.1:8067`), **Lab 68: Autonomous Agent Swarm Security & Byzantine Defense Lab** (`127.0.0.1:8068`), **Lab 69: Neural Weight Steganography & SafeTensors Supply Chain Defense Lab** (`127.0.0.1:8069`), and **Lab 70: Autonomous Kernel eBPF LSM Hotpatching & 0-Day Runtime Defense Lab** (`127.0.0.1:8070`).
3. **In-Browser Terminal Wargame (82 Tracks, 2,870 Challenges)**:
   A lightweight, zero-installation terminal simulation environment with authentic UNIX tooling (`connect`, `cat`, `submit`, privilege escalation) and 36 interactive visual architecture simulators.
4. **AI Security Agent Benchmark Leaderboard**:
   An automated evaluation engine measuring autonomous AI cybersecurity agents on Pass@1 exploit generation, tool safety, and zero-defect remediation across OWASP Top 10, KISA ISMS-P, and NIST CSF 2.0 standards.
