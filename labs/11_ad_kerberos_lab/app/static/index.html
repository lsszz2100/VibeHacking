🛡️ Enterprise AD & Kerberos Hardening Guide

            
침투 경로별 완화 기법과 SIEM/EDR 탐지 쿼리를 학습합니다.

          

          

            

              

                
1. AS-REP Roasting 방어

                
    
                  
  • 모든 도메인 사용자 계정에서 DONT_REQ_PREAUTH 플래그 강제 제거.
    • 
                  
  • PowerShell 감사 스크립트로 상시 점검: Get-ADUser -Filter {DoesNotRequirePreAuth -eq $True}.
    • 
                  
  • SIEM 탐지: Event ID 4768에서 Pre-Auth Type이 0 (None)인 이벤트 모니터링.
    • 
                

              

              

                
2. Kerberoasting 방어

                
    
                  
  • 서비스 계정에 **gMSA(Group Managed Service Accounts)** 적용 (128자 자동 순환 비밀번호).
    • 
                  
  • 일반 서비스 계정 암호 복잡도를 최소 30자 이상으로 설정.
    • 
                  
  • Kerberos 암호화 알고리즘을 AES-128/256으로 강제 (RC4 비활성화).
    • 
                  
  • SIEM 탐지: Event ID 4769에서 Ticket Encryption Type이 0x17(RC4)인 서비스 티켓 요청 감시.
    • 
                

              

              

                
3. DCSync 방어

                
    
                  
  • 도메인 루트 ACL에서 Domain Admins / Enterprise Admins 외 계정의 DS-Replication-Get-Changes-All 권한 즉각 박탈.
    • 
                  
  • Tiering Model(계층화) 적용으로 백업 및 관리자 계정 격리.
    • 
                  
  • SIEM 탐지: Event ID 4662 (Access Mask 0x100 on Domain-DNS object from non-DC IP).
    • 
                

              

              

                
4. Golden Ticket 방어

                
    
                  
  • krbtgt 비밀번호를 180일 주기로 2회 연속 변경 (이전 krbtgt 키 즉시 무효화).
    • 
                  
  • PAC Validation(Kerberos PAC 서명 검증) 활성화.
    • 
                  
  • MDI (Microsoft Defender for Identity) 비정상 TGT 티켓 이상 행위 탐지 도입.
    •
